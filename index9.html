Estilos internos

Estos estilos se agregan en el mismo archivo html, dentro de la etiqueta <head> y para agregarlos se utiliza el elemento <style>

Estilos externos

estos estilos son los que se recomienda utilizar, ya que ofrecen modularidad, facil mantenimiento, orden, eficiencia entre otras ventajas, para gregar una hoja de estilos externa, demtro de la etiqueta <head> se utiliza el elemento <link> donde se especiofica la ruta de nuestra hoja de estilos
